THE ALIBI PLAYBOOK

More friends. More questionable stories.

Published by Imposter Play · How this guide is made

Alibi runs on one shared phone, so a group can start without downloading apps or creating accounts. The most important setup is making sure everyone can hear the clues.

Three or four players

Use one imposter and keep hints on. With very few clues, a new imposter can struggle to find the topic. Start with familiar food or everyday objects, and allow a short practice round before recording a winner.

Five to eight players

This is a comfortable size for quick games. Start with one imposter. When the group understands the rules, add a second if the setup allows it. Always keep more civilians than imposters.

Nine to twenty players

Arrange a clear circle and agree on a clue order. Two or three imposters can make discussion more interesting. Give each person a chance to explain a clue before the loudest players settle the vote. A five- or eight-minute discussion timer helps larger groups.

Keep the phone handoff private

Hand the phone directly to the named player. They reveal the card only when the screen faces them, then use Hide card & pass the phone. If the screen hides automatically, the same player can peek again before moving on.

A group decision, not a popularity contest

The accusation screen asks the group to select exactly the configured number of suspects. Ask everyone for a reason tied to the clues. If the group needs more time, return to discussion rather than making a rushed choice.

Playing without internet

Visit the game once with a connection and let it finish loading. Supported browsers cache the game files for later offline use. Settings, custom words and used-word history stay on that browser. This edition does not connect players on separate devices.

Enough theory. Who’s bluffing?

Choose a topic, deal the cards and see whose story holds up.
